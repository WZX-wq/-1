鲲穹 AI 创影灵境完整版 2.4.15

使用方式
将压缩包完整解压到可写的文件夹，双击 main.exe。
必须保留 _internal、soft_pic、音乐、片尾和模板等全部目录，不能只拷贝 main.exe。
不要直接在压缩包内运行，也不要混用旧版本的 _internal。
配音设置仅提供微软 Edge TTS 和百度 TTS；默认每条视频随机选取音色，取消勾选后使用手动选定音色。
微软配音基于 edge-tts 7.3.1；可刷新微软在线音色列表。
视频中间阶段统一放入隐藏工作目录，输出目录只保留最终视频；背景音乐处理失败会明确提示，不会把无 BGM 中间片当成成片。
本版保留 AI 处理、手动合成视频和删除模板的确认判断，点击 Yes 执行，No 或关闭确认框取消。
换电脑后如果之前保存的片尾绝对路径失效，程序会自动使用软件包内 endCredits 文件夹中的视频。
本版修复图片、地方美食和节日风俗攻略的数据结构，旧版损坏的缓存文案会重新生成。
水印图片优先使用所选路径或软件目录中同名图片；未设置或图片缺失时会提示跳过水印并保留视频。
背景截图处理不会删除导入或缓存的原视频素材，方便换电脑后继续本地生成。
本版修复复合地点关键词未命中时继续尝试相关短词和后续标签，并统一离线地区筛选行为；AI 返回混合标签结构时会先规范化再写入。

AI 功能
本私人包已内置豆包默认 Key，无需另填 Key 或下载 Python、VC++ 等依赖。
云端文案生成仍需要联网，且服务商账户和余额必须有效。
默认启用同档位模型自动更新，每日首次 AI 任务检查，生成成功后切换；失败保留原模型。
可在 AI 设置修改账号、模型或取消自动更新，保存后后续请求生效。
欠费、密钥失效、模型关闭会分别提示，连续三次系统失败停止，内存不足立即停止并提示处理方式。

安全与兼容
内置 Key 可以从客户端提取，此私人包仅供本人及可信电脑使用，不要公开分享或上传公开仓库。
当前在 Windows 11 x64 验证，保留 Server 2016 兼容运行库；其他系统需实机确认，不支持所有电脑或操作系统。
不要删除正在使用的配置或素材；遇错请保留完整错误截图和日志。
