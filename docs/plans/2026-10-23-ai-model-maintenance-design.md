# 完整版 AI 长期维护与私人包内置密钥

## 目标

复用现有 OpenAI 兼容 SDK 和火山方舟官方模型目录，不新增供应商、账号或依赖。
完整版默认使用已验证的豆包 Lite；每日首次 AI 任务检查同档位新版本，真正生成成功才切换，失败保留旧模型。
余额不足、密钥失效与模型关闭分别提示，系统连续失败仍按三次停止。

## 密钥交付

用户要求 API Key 内置，私人构建通过 VIDEO_AI_EMBED_CONFIG 显式指定开发机上被 Git 忽略的配置。
构建工具在操作系统临时目录生成私有模块，PyInstaller 将其编译到 EXE 的 PYZ 中，随后删除临时源文件。
普通公开构建不含真实 Key，公开仓库仅保存构建机制。不得把私人 EXE、构建缓存或 ZIP 上传到公开仓库。

运行时优先级为环境变量、用户本地设置、内置默认配置。内置 Key 仅在完全一致的接口地址上使用，避免用户更改服务商地址后误发 Key。
自动更新模型时仅落盘接口地址、模型名称和开关，不把内置 Key 写入外部配置。
任何客户端内置密钥都可以被提取；此方案只适合用户自己或可信电脑，不等同于服务端密钥保护。

## 验证与边界

单元测试覆盖配置优先级、无配置启动、错误分类、模型筛选与切换、候选失败回退、不泄露内置 Key。
真实豆包请求验证文案、话题、标签与工作簿输出；发布后检查嵌入模块、兼容 DLL、资源和启动。
维持目录式完整版以保留启动性能，必须复制完整目录，不能只复制 EXE。
云服务仍需账号和余额有效，不能保证供应商永久维持任一型号或接口。
