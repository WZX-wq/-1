# 三农导入范围与本地素材设计

## 目标

三农独立版只处理用户本次导入 Excel 中的标题，只使用发布目录
`cacheAFRVideo` 中的本地 MP4。程序启动后保持空闲，导入成功后才允许开始。

## 数据流

标题导入结果携带所选账号和规范化后的完整标题列表。UI 将二者作为一次运行的不可变范围传给生成服务；生成服务每次领取标题时把该列表传给仓库，仓库使用参数化的
`title IN (...)` 条件，同时保留账号、三农类型、未生成状态和当天失败过滤。因此数据库中不属于本次 Excel 的历史标题不会被领取。切换账号或重新选择文件会清空范围并重新锁定开始按钮。

素材阶段不再查询素材数据库，也不调用下载接口。合成器扫描运行目录下的
`cacheAFRVideo/*.mp4`，只接受数字文件名，随机选择当前视频尚未使用的素材，再沿用原有 FFmpeg 截取和合成流程。每条视频重新建立已用集合，所以素材可跨视频复用；若本地可用素材少于片段数，则立即抛出包含目录、素材数和已用数量的错误。

## 验证

自动测试覆盖导入标题白名单、单账号范围、账号切换失效、本地素材选择、不重复和素材不足。发布测试要求打包目录包含本地 MP4；构建前使用 FFprobe 验证素材可读，构建后再执行依赖、自检和启动静置验证。
