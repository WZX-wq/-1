# 三农独立版 UI 设计

## 目标

为 `三农视频生成.exe` 增加与原版一致的深色 PyQt6 界面。程序启动后自动开始现有三农生成服务；所有账号标题耗尽或发生错误时窗口保持打开，用户能看到明确状态和完整日志。

## 界面

- 窗口标题为“三农视频自动生成”，使用现有 `tb.ico`。
- 延续原版颜色：页面 `rgb(39,40,42)`、工作区 `rgb(22,23,25)`、输入区 `rgb(56,56,56)`、主色 `rgb(19,171,234)`。
- 左侧显示从 `video_model_set/*.txt` 发现的账号列表和输出位置。
- 右侧显示运行状态、成功数量、失败数量、已耗尽账号数量和实时日志。
- 底部提供开始/再次运行、停止、打开输出目录、打开日志目录四个命令。
- 启动窗口后自动运行。没有可用标题时显示“任务完成，所有账号均无可用三农标题”，不自动关闭。

## 线程与状态

UI 主线程只处理界面。`GenerationWorker(QThread)` 调用现有 `SanongGenerationService.run(accounts)`；服务通过线程安全的停止事件在标题边界响应停止请求。日志由自定义 `logging.Handler` 转成 Qt 信号，禁止工作线程直接操作控件。

状态为“准备就绪、运行中、正在停止、任务完成、运行失败”。运行中禁用开始按钮并启用停止按钮；结束后恢复。关闭正在运行的窗口时先请求停止，当前片段完成后再关闭，避免销毁仍在运行的 QThread。

## 打包与兼容

PyInstaller 入口改为 `sanong_gui.py` 且 `console=False`。发布包使用仓库已有的兼容版 PyQt6 和 ICU 转发运行库，保留 Python、FFmpeg、VC++ runtime、账号配置和音乐。`--check` 仍走原有无领取自检并返回原退出码。

目标范围保持 Windows 10/11 x64 和 Windows Server 2016/2019/2022 x64。目标电脑无需安装 Python、PyQt6、FFmpeg 或 VC++ Redistributable。

## 验收

- 单元测试验证账号显示、结束后窗口常驻、状态摘要、停止请求和目录按钮。
- 源码 UI 在 offscreen 模式渲染截图并人工检查无重叠、文字可读。
- 完整回归套件通过。
- 重新构建发布目录，验证 Qt/ICU/平台插件及运行库齐全。
- 从中文空格目录、空 `PATH` 启动，确认窗口标题可见且进程不会因标题耗尽退出。
