# 三农独立版原版界面与标题导入设计

## 目标

三农独立版直接复用原版 `Ui_new_batch_ai_autocut` 页面结构，让熟悉原程序的用户按原位置操作。程序继续在启动后自动生成；全部标题耗尽后保持窗口打开。用户可以在同一页面选择 Excel、限定账号、导入标题并再次开始生成，不再运行 `uploadTitle.py` 或使用固定目录。

## 页面

- 使用原版 1353 x 949 深色无边框窗口、顶部“创影灵境”标题栏、最小化/最大化/关闭按钮和 `soft_pic` 图标资源。
- 左下保留原版文件区：模板选择映射为账号配置，限定账号显示当前账号，限定类型固定为“三农素材通用”。
- “标题文件导入”的 `+添加` 打开 `.xlsx` 文件；旁边原“AI处理”按钮改为“导入标题”。文案和标签位置显示“导入后自动生成”，不要求用户准备两个附加文件。
- 原版左下日志框显示导入、生成、停止、失败和汇总信息。
- 右侧固定显示原版“生产视频”页。保留输出位置、随机模板、自动生成等原位置，隐藏片尾、上传、模板保存等与独立三农版无关的控件。
- 右侧下半区显示运行状态、成功数、标题失败数、耗尽账号数，并提供停止、打开输出目录、打开日志目录。

## 标题导入

- Excel 第一列是标题。首格等于“标题”或 `title` 时视为表头并跳过；否则第一行也作为标题导入。因此 `文案0410.xlsx` 的 200 条标题不会漏掉第一条。
- 空白标题被忽略；重复标题在内存中去重并保持原顺序。第二列及后续列不写入数据库，现有三农文案与标签服务在生成时自动处理。
- 用户必须从现有账号配置中选择目标账号。数据库写入固定 `title_type = 6`，使用 `INSERT IGNORE` 跳过数据库已有重复项。
- 导入放在 `QThread` 中执行，避免数据库连接阻塞界面。结束后日志显示读取、写入和跳过数量；导入失败只更新状态和日志，不关闭窗口。
- 正在生成时禁用导入；正在导入时禁用生成，防止同一账号同时读取和写入标题。

## 生成与关闭

- 启动窗口后仍自动调用现有 `SanongGenerationService`。
- 标题耗尽后显示“任务完成，所有账号均无可用三农标题”，窗口常驻，“开启自动生成”变为“再次运行”。
- 点击停止或运行中关闭窗口时，服务在当前标题边界协作式停止；导入线程完成前关闭请求同样延后。
