# 三农独立版 UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为独立三农生成器增加原版风格、自动运行且任务结束后常驻的 PyQt6 页面。

**Architecture:** 新增单独 UI 入口和 QThread 工作器，复用现有 `sanong_runner.build_runtime` 与 `SanongGenerationService`。服务增加协作式停止事件；打包入口切换到 UI，并收集兼容版 Qt/ICU 运行库。

**Tech Stack:** Python 3.12、PyQt6、PyInstaller、unittest

**Spec:** `docs/superpowers/specs/2026-09-24-sanong-ui-design.md`

## Global Constraints

- 启动后自动生成，只处理 `title_type = 6`，直到全部账号无标题。
- 标题耗尽、成功或失败后 UI 均不得自动关闭。
- 生成核心继续由 `sanong_generation` 共享，不复制算法。
- 发布目录支持 Windows 10/11 x64 与 Server 2016/2019/2022 x64。
- 仓库没有 Git，不执行 worktree 或 commit 步骤。
